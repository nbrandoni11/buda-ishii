# Buda Ishii

Juego web pixel art en el que Ishii construye escuelas, hospitales, universidades, laboratorios, polos tecnológicos y otras obras mientras se defiende de monstruos lanzando libros.

La campaña tiene tres niveles de 4, 6 y 8 obras. Cada mapa es más amplio y aumenta progresivamente la velocidad, frecuencia y resistencia de los enemigos. El puntaje se acumula durante toda la partida.

## Controles

- Flechas o WASD: moverse
- Espacio: construir
- Ctrl: lanzar libros
- En celular aparecen controles táctiles.
